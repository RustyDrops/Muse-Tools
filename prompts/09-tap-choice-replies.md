# 09 — Tap-choice replies

Cut typing: when a question has a small set of real answers, make it one tap.

> From now on, when you ask me something with 2-3 clear options, present them as tap-choice buttons instead of an open question. Keep one option that lets me say I've already handled it, where that fits. Never use buttons for an open-ended question — ask that in plain text.

Works best for decisions the monthly audit (prompt 06) surfaces, approvals, and next-step picks. It fails when the options are fake — if the real answer might be "none of these," say so in text instead.
