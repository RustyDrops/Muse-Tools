# 07 — Back up your companion first

Before any big memory or personality edit, take a backup you can restore from.

> Back up my core files — MEMORY.md, SOUL.md, IDENTITY.md, USER.md, and my proactive preferences — into a dated backup folder. Show me a checksum for the main memory file so I can verify the copy matches. Never overwrite an older backup; each one gets its own date.

Make it weekly and automatic once you like it:

> Repeat that backup every week on the same day, keep the last 4, and only tell me if one fails.

Tested: a copy made this way checksums identically to the live file. A backup you have not verified is a hope, not a backup.
