# Prompts

Copy-paste prompts for the memory optimizations in this repo. Each one is written to hand to your own Muse as-is — replace the example paths with your own.

| Prompt | When to use it |
| --- | --- |
| `01-split-memory-into-topics.md` | Your core memory file is growing and mixes too many domains |
| `02-daily-memory-cleanup.md` | Once a day, to keep the core file under its cap |
| `03-handoff-summary.md` | A conversation is getting long and the work should continue in a fresh chat |
| `04-lean-loading-rules.md` | Standing instructions — the everyday habits that keep context small |
| `05-design-system-styling-setup.md` | One-time setup — compare design systems on the same test card, pick your own styling, lock it into one reusable theme file |
| `06-monthly-housekeeping-audit.md` | Once a month — audit goals, tracked items and scheduled tasks; decisions only, as tap choices |
| `07-backup-your-companion.md` | Before big edits, then weekly — verified backup of your core files |
| `08-identity-and-soul-setup.md` | One-time setup — fill in blank Identity/Soul fields so side chats stop drifting |
| `09-tap-choice-replies.md` | Standing habit — answers with 2-3 real options become one tap |
| `10-side-chat-rooms-by-role.md` | When chats pile up — one room per job, main chat orchestrates |
| `11-month-content-plan-that-doesnt-invent.md` | Planning a month of social posts from your own facts only, nothing invented |
| `12-pdf-to-podcast.md` | Turning one PDF you supply into a two-host podcast script, claims tied to pages, script approved before audio |

Run them in order the first time: split first, then set the daily cleanup going, then use handoffs and the lean rules day to day.

Prompts 06–10 come from testing a Japanese Muse tips roundup by [@memuringo7544](https://x.com/memuringo7544/status/2123749668056432769) (74 linked tips, Nov 2026) against a real, heavily-used setup. Most of the roundup was already covered here or didn't survive testing — these five did. The refusal-bypass and companion-romance sections were deliberately left out.
