# Prompts

Copy-paste prompts for the memory optimizations in this repo. Each one is written to hand to your own Muse as-is — replace the example paths with your own.

| Prompt | When to use it |
| --- | --- |
| `01-split-memory-into-topics.md` | Your core memory file is growing and mixes too many domains |
| `02-daily-memory-cleanup.md` | Once a day, to keep the core file under its cap |
| `03-handoff-summary.md` | A conversation is getting long and the work should continue in a fresh chat |
| `04-lean-loading-rules.md` | Standing instructions — the everyday habits that keep context small |
| `05-design-system-styling-setup.md` | One-time setup — compare design systems on the same test card, pick your own styling, lock it into one reusable theme file |

Run them in order the first time: split first, then set the daily cleanup going, then use handoffs and the lean rules day to day.
