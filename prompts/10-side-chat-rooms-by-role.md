# 10 — Side-chat rooms by role

One room per job beats one giant main chat — and beats 100 random chats.

> Suggest side-chat rooms by role for how I actually use you — for example an Email Reception Room that summarises new mail each morning, deletes promos, unsubscribes from newsletters that don't need a login, and sends only important or security alerts to my main chat. Routine reports stay in that room. Before creating any room, show me the list and let me pick.

Rules that keep rooms useful:
- A room's rules live in that room; the main chat orchestrates and decides.
- Don't delete workrooms — archive them. Deleting loses work the main chat can't reproduce.
- If rooms pile up, run prompt 06. If your Spaces pile up instead, ask Muse to build one "App Dock" Space that lists all the others, and pin only the dock.
