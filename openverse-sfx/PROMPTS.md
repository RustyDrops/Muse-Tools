# Prompts - using Openverse sound effects well

Copy a prompt, replace the brackets, hand it to your Muse. Each one runs
the workflow in SKILL.md: jobs first, CC0 first, license verified on the
detail record, files checked, credits written.

## 1. Sound a short video

> Add sound effects to my [60 second vertical video / Short] about [topic].
> First list the sound jobs from the script: hook, typing or writing moments,
> transitions, reveals, payoff, ending. Then search Openverse for one CC0
> sound per job, verify each license on its Openverse detail page, download
> to a sounds/ folder, and check each file (duration, clipping, silence).
> Write CREDITS.md with title, creator, license and source link for every
> sound. Show me the job list with the chosen sound for each before you
> edit anything. No generative audio, nothing posts.

## 2. Sound a game I built

> Sound my game at [path]. Read the code and list every event that should
> make a sound: player actions, pickups, hits, win and lose states, and
> every UI press. Search Openverse for one short CC0 sound per event
> (0.05 to 0.5 sec for most), verify each license on its detail page, and
> download them into the game's sounds/ folder with a CREDITS.md. Wire
> them in: preload at start, play on the event, slight random pitch on
> repeating sounds, master volume and a mute toggle. Show me the event
> to sound map before you change code.

## 3. UI sounds for an app or site

> Pick a small, consistent UI sound set for [app or site]: click, toggle,
> success, error, send, delete. All from Openverse, all CC0, all from a
> similar family (clean electronic, or soft real world, not a mix).
> Download to sounds/, write CREDITS.md, and add a settings toggle to
> turn UI sounds off. Keep every sound under 0.5 sec and quieter than
> speech or video audio.

## 4. An ambience bed, legally clean

> Find a loopable ambience for [setting: rain on a roof, forest morning,
> cafe murmur, spaceship hum] on Openverse. CC0 strongly preferred, CC BY
> only if the credit line can ship with the project. Check the full file,
> not just the start: no voices, no sudden events, no clipping, and test
> the loop point. Download it, write its credit line, and tell me the
> exact length and whether it loops cleanly before using it anywhere.

## 5. Audit sounds I already have

> Audit the sound files in [folder]. For each one, tell me: where it came
> from if that can be established, what license covers it, whether it can
> be used commercially, and whether attribution is required and where.
> Flag any file with no clear license as do not ship. Write the results
> into a CREDITS.md and a short do not use list. Do not guess a license
> you cannot verify, say unverified instead.
