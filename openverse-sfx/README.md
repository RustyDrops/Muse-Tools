# Openverse Sound Effects

Free, license checked sound effects for videos, games and apps, from Openverse. A small stdlib only Python tool (`openverse_sfx.py`) searches the live Openverse API, prefers CC0 public domain sounds, downloads them, and writes the CREDITS.md with each sound's exact license and source. `SKILL.md` is the full workflow: list the sound jobs first, verify every license on its detail record, check each file before use, plus a game section with an event to sound map and preload and play code for HTML games and pygame. `PROMPTS.md` has five copy paste prompts: sound a short video, sound a game, pick UI sounds, find a legal ambience bed, and audit sounds you already have. `examples/` holds three tested CC0 sounds (typing clicks, a bubble pop, a payoff chime) with their full Openverse records.

Copy `SKILL.md` into your Muse's custom skills folder, or just ask your Muse to sound your next video or game and point it here.
